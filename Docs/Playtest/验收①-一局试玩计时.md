# 验收①「一局 35–50 分钟」试玩计时指南

> GDD 第 7 章 STEP 3 验收①：**一局完整通关时长落在 35–50 分钟**。
> 这条是**人的判断**，脚本永远绿不了它 —— 这篇写给拿秒表的人。

---

## 0. 先说清楚：现在能验什么、不能验什么

| | 现状 | 能不能验 |
|---|---|---|
| **战斗观看时间**（GDD 核心循环：30 秒/场） | 灰盒窗口里战斗是 Edit 模式**瞬时算完**的（无动画、无前摇、无关键回合干预） | ❌ 验不了 —— 要等表现层 |
| **节点决策时间**（GDD 核心循环：2 分钟/节点） | 窗口里能完整走：读节点名 → 读天时 → 看敌方阵容 → 选分支 → 看战报 | ✅ 可以实测 |
| **一局总时长** | = 决策实测 + 战斗观看（预算） | ⚠ 半实测半推算 |

所以本指南给的是**两个数**：**实测决策合计** 与 **推算总时长**（= 实测 + 21×30 秒）。
推算落在 35–50 只是"内容量假设成立"，**真实时长仍要等表现层做完再复测一次**。

---

## 1. 准备（1 分钟）

1. 打开 Unity 工程 `D:/Unity_Project/MYRIAD/WanXiang`。
2. 菜单 **万相 / 节气 / 节点图（灰盒）**。
   - 窗口顶部右侧会显示内容来源（`内容：30 只异兽（ContentCatalog）`）。
   - 若显示"未找到 ContentCatalog"，先跑 **万相 / 融合 / ① 导入内容**。
3. 右上 **局种子**：想复现别人的一局就填同一个数；随手试玩保持默认即可。
4. 点 **▶ 开始试玩计时**（按钮会变成「⏱ 打标记（这一段读完了）」）。

---

## 2. 试玩流程（一局 21 场，约 15–25 分钟真人操作）

每一场的动作固定，**看完就点**（点了会自动打标记，记下这一段的决策耗时）：

1. 读节点行：`节气名 · 天时名`（例如 `19 立冬 · 水始成冰`）。
   未翻译的会写「（天时未翻译）」—— 那是我方内容缺口，不是你漏看了。
2. 看「选择下一步」里每条分支后面的 **敌方阵容预览**（谁、什么五行、站哪）。
3. 点一条分支 → 战斗瞬间跑完 → 看「战斗记录」里新增的那一行
   （结局 / 回合数 / 指纹）。
4. 顺手看一眼 **余气面板**：`余气 · 立春 东风解冻（强度减半，还剩 2 个节点）`
   —— 跨幕时它决定"我这一场还背着上一季的什么规则"。
5. 重复到本幕 4 个节点走完 → 出现 **⚔ 迎战守关** 按钮 → 点掉。
6. 幕间会换季（春→夏→秋→冬→长夏），余气重新生成。

走完 5 幕 = 21 场。**中途败北就重开**（肉鸽：死亡即结束）。

### 三种跑法，按目的选

| 目的 | 怎么做 | 耗时 |
|---|---|---|
| **验时长**（本指南的主用途） | 逐场点分支，每场都读节点名与天时 | 15–25 分钟真人操作 |
| 只想看有没有明显 bug | 「本幕跑完（到守关前）」+ 手动点守关 | 3–5 分钟 |
| 只想看整局结论 | 「自动跑完整局」，看顶部状态与记录列表 | 秒级 |

## 4. 怎么读这个数

参照 GDD 1.3 核心循环表（预算）：

```
战斗层  30 秒 × 21 场          = 10.5 分钟
节点层   2 分钟 × 16 个常规节点 = 32.0 分钟
────────────────────────────────────────
目标                              42.5 分钟   ← 35–50 区间的中段
```

| 推算结果 | 说明 | 该做什么 |
|---|---|---|
| **< 35 分钟** | 决策太快：玩家没什么可犹豫的 | GDD 7 章卡点预警的原话是「节气要有记忆点」——检查节点信息量、敌方阵容差异、选择代价是否够重（要不要真的放弃 2 个节点） |
| **35–50 分钟** | 内容量假设成立 ✓ | 等表现层做完复测一次，确认战斗观看真按 30 秒/场 |
| **> 50 分钟** | 决策拖沓 | 检查是否每个节点都需要 2 分钟；可能是节点信息太碎或战斗回合数（当前灰盒常见 9–12 回合）偏长 |

⚠ **别把"推算"当"实测"汇报**：灰盒阶段真实时长几乎完全取决于表现层的战斗节奏
（动画时长、关键回合干预的等待）。这条验收在表现层就位前只能算**半验**。

## 5. 顺手一起做的两条（GDD 7.1 验证顺序表）

同一次试玩可以顺手把另外两条主观项也做了（都是"玩完问一句话"）：

- **第 3 条（节气有没有记忆点）**：玩完一幕，合上计算机，**复述你记得的节气名与效果**。
  复述不出 = 天时区分度不足或节点名信息量不够。
- **第 4 条（一局有没有重玩欲）**：连续开 3 局（换种子），记一句"想不想再开一局"。
  不想 = 流派分化不足，或局外成长反馈太慢（局外孵蛋已经能出宿主，可以观察
  「孵出新宿主 → 下一局换阵容」这条链路有没有爽感）。

## 6. 已知会干扰判断的两件事

1. **灰盒技能是占位**：90 条技能描述还没逐条翻译，当前按"职业 + 类型"生成固定套路。
   ⇒ 战斗回合数与"看起来有没有意思"都不代表正式内容，**时长结论以节点/战斗场次为准**。
2. **平局率偏高**（回合上限 30 + 治疗/护盾体系）：目前实测 5/5 随机对阵打平。
   ⇒ 如果试玩里频繁遇到平局，那是数值问题而不是你的操作问题，已挂账给策划。
