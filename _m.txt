refactor(battle-ui): UI 全部进生成器 —— prefab 可见可调（用户明确要求）

用户批评："不要用代码生成 UI，应该在战斗面板（生成器）里做好"
（项目规范就是 UGUI 由生成器拼装进 prefab ✓ 我之前为了省改动一直代码自建 ✗）

本次把三块 UI 全部搬进 UIPanelPrefabBuilder.BuildBattle：
  · Root_Action      战记操作区（此前已进）
  · Root_OrderList   行动顺序：标题 + 8 行（每行 Head 头像 + Tmp_Name）
  · Root_SkillTip    战记悬浮提示：Tmp_Tip
并 Bind：_orderPanel / _orderRows（BindArr）/ _tipPanel / _tipText

BattlePanel 改为"绑定优先 + 自建兜底"：
  · 字段全部 [SerializeField]
  · BuildOrderList：prefab 有 → 用 _orderRows[i].Find("Head" / "Tmp_Name") 取行内引用，不建控件；
    没有（旧 prefab）→ 代码自建一套兜底
  · BuildSkillTip：prefab 有 → 取引用 + 补 CanvasGroup；没有 → 自建

真机验证（MCP）：
  Root_Action ✓  Root_OrderList ✓（9 个子节点：标题+8行）  Root_SkillTip ✓
  首行子节点 = Head / Tmp_Name ✓
  绑定 _orderPanel ✓  _tipPanel ✓

意义：这些 UI 现在在 prefab 里可见、可调位置、美术能接手、也便于对象池化管理。
